# portfolio-2026

Personal portfolio for Lisa Herzberg. Frontend-only (no backend) — React + TypeScript + Vite + Tailwind CSS v4 + React Router v7 + Framer Motion.

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
```

## Scripts

- `npm run dev` — dev server
- `npm run build` — typecheck + production build
- `npm run preview` — preview the build
- `npm run typecheck` — tsc --noEmit
- `npm run lint` / `npm run lint:fix`

## Conventions

See `CLAUDE.md` (code conventions) and `AGENTS.md` (workflow). Mock data lives in `src/data/`; replace `public/mock/*` images and `public/resume.pdf` with real assets when ready.
